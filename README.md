# RealSitesOpen

RealSitesOpen — каталог сайтов, VPN-сервисов, аниме-ресурсов и системных оболочек.

## Публикация через GitHub Pages

1. Загрузите содержимое этой папки в корень репозитория GitHub.
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Сохраните настройки.

Страница запускается из `index.html` и не требует сборки. Некоторые значки загружаются из внешнего каталога и требуют интернет-соединения.
